# Trading Bot Project

این پروژه به‌صورت استاندارد بازآرایی شده است تا بک‌اند و فرانت‌اند جدا باشند.

## ساختار پروژه

- backend/: کدهای بک‌اند و موتور ترید
- frontend/: برنامه React/Vite برای رابط کاربری
- backend/Jsons/: فایل‌های تنظیمات و استراتژی

## اجرا

### بک‌اند
```bash
cd backend
python Main.py
```

### فرانت‌اند
```bash
cd frontend
npm install
npm run dev
```

## نکته
- فایل‌های تنظیمات و داده‌ها در backend/Jsons نگهداری می‌شوند.
- برای توسعه آینده، کدهای بک‌اند و فرانت‌اند جدا از هم نگهداری می‌شوند.
