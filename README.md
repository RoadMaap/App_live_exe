🚀 RoadMap Trader | AI Algorithmic Terminal

RoadMap Trader is an enterprise-grade algorithmic trading terminal that bridges the gap between no-code AI generation and high-frequency MetaTrader 5 execution.

🎯 هدف پروژه (Project Purpose)

هدف اصلی RoadMap Trader، حذف کامل پیچیدگی‌های برنامه‌نویسی برای معامله‌گران و تبدیل آن‌ها به توسعه‌دهندگان الگوریتمی (Quant Developers) با کمک هوش مصنوعی است.
این پلتفرم به جای اینکه فقط یک نرم‌افزار ترید باشد، یک "کارخانه تولید ربات" است. کاربر با استفاده از قالب‌های استاندارد و ضد-کرشِ تعبیه شده در سیستم، می‌تواند استراتژی‌های پیچیده خود را به زبان ساده به ChatGPT یا Claude بگوید و کدهای تولید شده را مستقیماً در یک موتور معاملاتی قدرتمند و بدون باگ (Zero-Crash Engine) روی متاتریدر ۵ اجرا کند.

🏗 معماری و نحوه کار (How It Works)

این نرم‌افزار از یک معماری Hybrid Core (هسته ترکیبی) بهره می‌برد:

فرانت‌اند (React.js + Tailwind CSS): یک رابط کاربری نئونی، مدرن و ریسپانسیو که تمام تنظیمات مدیریت ریسک، مانیتورینگ زنده لاگ‌ها و وضعیت اتصال را به کاربر نشان می‌دهد.

پل ارتباطی (Eel Framework): وظیفه انتقال بی‌درنگ (Real-time) دستورات کاربر از محیط وب (React) به هسته پایتون را بر عهده دارد.

بک‌اند و موتور پردازش (Python): - Live Signal Engine: دیتاها را از بازار می‌خواند و به استراتژیِ تولید شده توسط هوش مصنوعی پاس می‌دهد.

Error Handler & AI Debugger: یک لایه محافظتی که جلوی هرگونه کرش کردن ربات را می‌گیرد و در صورت بروز خطا در کد هوش مصنوعی، خطای مربوطه را به شکل یک پرامپت (Prompt) آماده برای ارسال مجدد به ChatGPT روی داشبورد چاپ می‌کند.

لایه اجرا (MetaTrader 5): دستورات خرید، فروش، مدیریت پوزیشن‌ها (Partial/Breakeven) مستقیماً روی سرورهای متاتریدر اجرا می‌شوند.

✨ ویژگی‌های کلیدی (Key Features)

🤖 ۱. ربات‌ساز هوش مصنوعی (AI Strategy Builder)

قالب‌های برنامه‌نویسی از پیش آماده و بهینه‌شده (Bulletproof Template) که کاربر آن را کپی کرده و به هوش مصنوعی می‌دهد. این سیستم دارای دستورالعمل‌های پنهان (AI Prompts) است تا کدهای خروجی کاملاً با استانداردهای متاتریدر هم‌خوانی داشته باشند.

🛡️ ۲. موتور اجرای ضد-کرش (Zero-Crash Core Engine)

استفاده از سیستم پیشرفته safe_execute که کدهای نوشته شده توسط هوش مصنوعی را در یک محیط ایزوله اجرا می‌کند. اگر هوش مصنوعی اشتباه کند (مثلاً به جای خروجی عدد، متن بدهد)، موتور به جای بسته شدن، خطا را دور می‌زند و فقط به کاربر هشدار می‌دهد.

🌍 ۳. فیلتر هوشمند اخبار (Smart News Filter Daemon)

یک سرویس مستقل (Microservice) که اخبار مهم اقتصادی (High-Impact) جهان را رصد می‌کند و در زمان انتشار اخبار مربوط به جفت‌ارزهای اصلی (مانند EUR و USD)، موتور معاملاتی را قفل می‌کند تا از نوسانات شدید (Slippage) در امان بماند.

💼 ۴. مدیریت ریسک سراسری (Global Risk Management)

Target Lock: تعیین سقف سود روزانه (قفل شدن ربات پس از رسیدن به تارگت).

Auto-Breakeven & Partial Close: مدیریت هوشمند پوزیشن‌های باز برای حفظ سود.

Risk Modes: محاسبه خودکار حجم معاملات بر اساس درصد از موجودی، ریسک ثابت دلاری یا حجم ثابت.

🛠 راه‌اندازی و نصب (Installation & Setup)

پیش‌نیازها

نصب بودن Python 3.12 یا بالاتر.

نصب بودن Node.js (نسخه 18 به بالا).

نرم‌افزار MetaTrader 5 (ترمینال کلاینت).

مرحله اول: راه‌اندازی بک‌اند (Python)

ابتدا پکیج‌های پایتون را نصب کنید:

pip install pandas numpy pandas_ta mplfinance MetaTrader5 eel


مرحله دوم: راه‌اندازی فرانت‌اند (React)

وارد پوشه frontend شوید.

پکیج‌های Node را نصب کنید:

cd frontend
npm install


نسخه نهایی (Production Build) را برای اتصال به پایتون بسازید:

npm run build


مرحله سوم: اجرای نرم‌افزار

به پوشه اصلی پروژه (کنار فایل Main.py) برگردید و برنامه را اجرا کنید:

python backend/Main.py


نکته: نرم‌افزار به صورت خودکار یک پنجره شبیه به نرم‌افزارهای دسکتاپ باز می‌کند و به متاتریدر ۵ متصل می‌شود.

🧠 آموزش ساخت استراتژی با هوش مصنوعی (AI Workflow)

در داشبورد نرم‌افزار به بخش AI Builder (ربات‌ساز هوش مصنوعی) بروید.

روی دکمه "Copy Architecture" کلیک کنید تا قالب استاندارد کپی شود.

قالب را در ChatGPT یا Claude پیست (Paste) کنید و درخواست خود را بنویسید. مثال:

"با استفاده از این قالب، یک استراتژی بنویس که هرگاه اندیکاتور RSI به زیر 30 رسید بخر، و اگر بالای 70 رفت بفروش."

کد پایتونِ تولید شده را در یک فایل (مثلاً MyBot.py) ذخیره کنید.

به بخش Strategy Manager در داشبورد بروید، فایل را Import کنید، تنظیمات ریسک را انجام دهید و دکمه Start را بزنید!
